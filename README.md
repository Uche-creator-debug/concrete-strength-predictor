# 🏗️ Concrete Compressive Strength Predictor

A machine learning web app that predicts the **28-day compressive strength** of concrete based on its mix ingredients.

### Features
- Built with **XGBoost** (R² = 0.9445)
- Interactive Streamlit interface
- Feature engineering (Water-Cement ratio + Total Binder)

### Live Demo
👉 [Open App](https://concrete-strength-predictor-6vcsaoamjknnf3mkjsw52a.streamlit.app)

### Tech Stack
- Python, XGBoost, Scikit-learn
- Streamlit (Frontend)
- Deployed on Streamlit Cloud
